## 1. 产品概述

个人相册应用是一款面向个人用户的本地化图片管理工具，支持图片上传、预览、相册分类、标签管理以及自定义轮播播放。所有数据存储在浏览器本地（IndexedDB），无需服务器，保护隐私。

- 解决个人照片分散、难以分类和展示的问题
- 目标用户：需要本地管理照片并制作个性化幻灯片展示的个人用户

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 个人用户 | 无需注册 | 使用全部功能 |

### 2.2 功能模块

1. **相册主页**: 相册列表、最近上传、快速操作入口
2. **相册详情页**: 图片网格展示、批量操作、标签筛选
3. **图片预览页**: 全屏预览、图片信息、标签编辑
4. **轮播编辑页**: 轮播配置、切换效果选择、文字叠加编辑
5. **轮播播放页**: 全屏播放、播放控制

## 3. 核心流程

**图片上传与管理流程**：用户进入主页 → 创建相册 → 上传图片（拖拽/选择） → 为图片添加标签 → 按标签筛选查看

**轮播制作与播放流程**：用户进入轮播编辑 → 选择图片 → 配置切换效果 → 添加自定义文字 → 设置播放参数 → 预览播放 → 全屏播放

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深色主题，主色为暖橙 `#E8845C`，辅助色为柔和米白 `#F5F0EB`
- **背景色**: 深灰 `#1A1A2E` 到 `#16213E` 渐变，营造沉浸式观影感
- **按钮风格**: 圆角胶囊按钮，hover 时微微上浮 + 发光效果
- **字体**: 标题使用 `Playfair Display`，正文使用 `DM Sans`
- **布局风格**: 左侧导航栏 + 右侧内容区，卡片式布局
- **图标风格**: Lucide 线性图标，与深色主题搭配

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 相册主页 | 相册列表 | 卡片网格布局，每张卡片含封面图+相册名+图片数量，hover 放大效果 |
| 相册主页 | 快速上传区 | 虚线边框拖拽区，拖入时边框发光动画，支持点击选择 |
| 相册详情页 | 图片网格 | 响应式网格，4-6列，hover 显示操作按钮浮层 |
| 相册详情页 | 标签筛选栏 | 水平滚动标签胶囊，选中态为暖橙填充 |
| 图片预览页 | 全屏预览 | 深色背景，图片居中，底部半透明控制栏 |
| 轮播编辑页 | 图片选择 | 左侧图片候选列表，右侧已选图片时间轴 |
| 轮播编辑页 | 效果配置 | 卡片式效果预览，点击选择，动画演示 |
| 轮播编辑页 | 文字编辑 | 实时预览画布，拖拽定位文字位置 |
| 轮播播放页 | 全屏播放 | 全屏沉浸式，底部浮动控制条，自动隐藏 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1024px
- 平板适配：网格列数减少，侧边栏折叠
- 移动端适配：单列布局，底部导航，触摸优化手势操作
